
# 🌷 Happy Mother's Day - Website

Website sederhana bertema Hari Ibu yang dibuat sebagai bentuk ungkapan cinta, kasih sayang, dan rasa terima kasih kepada ibu tercinta. ❤️

Website ini memiliki desain bernuansa pink pastel yang elegan, dilengkapi dengan animasi dan kartu ucapan digital yang dapat dibuka dan ditutup.

## ✨ Features

- Responsive Design: Bisa dibuka melalui HP, tablet, dan laptop.
- Sticky Navbar: Navigasi tetap berada di bagian atas saat halaman di-scroll.
- Hover Effect: Animasi pada menu navigasi.
- Greeting Card: Kartu ucapan digital untuk ibu.
- Popup Message: Kartu dapat dibuka dan ditutup kembali.
- Floating Hearts: Animasi hati yang bergerak.
- Photo Gallery: Galeri foto kenangan bersama ibu.
- Smooth Scrolling: Perpindahan halaman lebih halus.

## 🚀 How to Run

1. Clone repository:

```bash
git clone https://github.com/USERNAME/REPOSITORY.git
```

2. Masuk ke folder proyek:

```bash
cd website-hari-ibu
```

3. Buka folder menggunakan Visual Studio Code.

4. Jalankan file `index.html` menggunakan Live Server.

## 🌐 Deployment

Website ini dapat di-hosting secara gratis menggunakan GitHub Pages.

Langkah-langkah:

1. Upload seluruh file proyek ke repository GitHub.
2. Buka repository GitHub.
3. Masuk ke menu **Settings**.
4. Pilih **Pages**.
5. Pada bagian Build and deployment, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`.
7. Klik **Save**.
8. Tunggu proses deployment selesai.

Website kamu akan tersedia melalui alamat:

```text
https://USERNAME.github.io/REPOSITORY/
```
